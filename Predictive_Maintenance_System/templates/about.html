About PredictMaint

System overview, application pages, prediction workflow, feature set, and technology stack for this Flask-based maintenance scheduling tool.

System Overview

PredictMaint is a web-based predictive maintenance scheduling system built as the software deliverable of a machine learning dissertation. It allows maintenance engineers and plant supervisors to enter live machine operating parameters and instantly receive a failure risk prediction, probability breakdown, and prioritised maintenance recommendations — all powered by a trained XGBoost classifier.
